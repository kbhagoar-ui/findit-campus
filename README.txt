FINDIT CAMPUS — PROJECT README

Project idea
FindIt Campus is a student lost-and-found website prototype. It gives students one place to browse reported lost/found items and submit their own report.

Included files
- index.html: the single-page website
- style.css: responsive layout and visual styling
- script.js: sample listings, search/filter controls, report form and browser-only demo storage
- assets/favicon.svg: site icon
- posters/: two social post versions, one promotional creative, one event poster, and a before/after image-editing concept

How to run locally
1. Extract the ZIP.
2. Open index.html in a browser. For the simplest preview, double-click the file.
3. For a local server, open a terminal in this folder and run: python -m http.server 8000
4. Visit http://localhost:8000

How to publish with GitHub + Vercel
1. Create a GitHub repository called findit-campus.
2. Upload index.html, style.css, script.js, README.txt and the assets/ and posters/ folders.
3. Import the repository in Vercel and deploy it as a static site. No build command is required.
4. After deployment, update the site title/description if desired and use your actual Vercel URL in the assignment.

Important prototype limitations
- Listings are fictional demo examples, not verified reports from a real college.
- New reports are stored only in the same browser using localStorage; they are not shared with other students or sent to campus security.
- The contact method is used only in the browser demo and is not shown as a public field on the item card. This is not a production-safe reporting system.
- Before using this in a real campus, add secure authentication, a shared database, moderation, report verification, privacy controls and a clear handover process.
- The posters use fictional sample event details. Change date, time, venue and contact information before any real use.

Design direction
Navy, orange and pale green; friendly campus-focused illustrations; short headlines; clear actions; responsive layout for mobile and desktop.
